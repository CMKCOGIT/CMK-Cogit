Styleguide do site

Tokens (css/tokens.css, o mesmo arquivo da plataforma) e componentes do site institucional. Documentação interna: a pasta docs/ não vai para a hospedagem. Abra com node tools/preview.mjs em /docs/styleguide.html.

Cores

Texto só em pares AA (4,5:1). --color-neutral-400 só para borda/ícone decorativo. Preços e valores vêm do catálogo (js/data.js), nunca do HTML.
