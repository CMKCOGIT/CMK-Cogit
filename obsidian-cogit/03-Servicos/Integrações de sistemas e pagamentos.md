# Integrações de sistemas e pagamentos

Conexão entre APIs, meios de pagamento, WhatsApp e os sistemas que o cliente já usa. A partir de R$ 990 (1 integração padrão).

**Frente:** Ganhar eficiência · **Prazo:** definido na proposta

## O que já está no valor base

- 1 integração padrão (API documentada, um sentido)
- Testes e tratamento de erros
- 1 mês de suporte gratuito

## Adicionais mais pedidos

Não estão no valor base; somam ao orçamento:

- [Sincronização nos dois sentidos](../04-Catalogo/Itens/Sincroniza%C3%A7%C3%A3o%20nos%20dois%20sentidos.md)

- [Sistema sem API documentada](../04-Catalogo/Itens/Sistema%20sem%20API%20documentada.md)

## Perguntas para o briefing

- Quais sistemas precisam conversar?
- O sistema tem API documentada?
- Os dados vão nos dois sentidos?
- Qual o volume (por dia ou por mês)?
