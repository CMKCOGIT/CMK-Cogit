# COGIT — base de conhecimento

Vault do Obsidian com o funcionamento da COGIT: empresa, fluxos, serviços e o **catálogo de variações e funcionalidades com preço**, usado para orçar (inclusive no orçamento por funcionalidade da Jornada MVP).

> [!WARNING] Repositório público
> Esta pasta está no repositório `CMK-Cogit`, que é **público** no GitHub. Não escreva aqui senhas, dados de clientes, contratos ou números internos que não possam ser vistos por qualquer pessoa. Para isso, mova o vault para um repositório privado (veja [Instalar e configurar o Obsidian](00-Guia/Instalar%20e%20configurar%20o%20Obsidian.md)).
