Política de Privacidade

Última atualização: Agosto de 2026

1. Introdução

A CMK Cogit valoriza a privacidade e a proteção dos dados pessoais de seus usuários, clientes e parceiros.

Esta Política descreve como coletamos, utilizamos, armazenamos e protegemos informações pessoais.

2. Controlador dos Dados

A empresa responsável pelo tratamento dos dados é:

CMK Cogit

Endereço: São José do Rio Preto

Contato de privacidade: contato@cmkcogit.com.br

3. Dados Coletados

Podemos coletar:

Dados cadastrais

  • Nome;
  • Empresa;
  • CPF/CNPJ;
  • E-mail;
  • Telefone;
  • Senha.

Dados de utilização

  • Acessos;
  • Histórico de navegação;
  • Interações com plataforma;
  • Logs técnicos.

Dados comerciais

  • Solicitações;
  • Informações de projetos;
  • Histórico de atendimento;
  • Contratos.

4. Como Utilizamos os Dados

Os dados podem ser utilizados para:

Prestação de serviços

  • Criar contas;
  • Executar projetos;
  • Entregar funcionalidades.

Comunicação

  • Responder solicitações;
  • Enviar informações importantes;
  • Atualizar usuários.

Melhoria dos serviços

  • Analisar uso;
  • Corrigir problemas;
  • Desenvolver melhorias.

Segurança

  • Prevenir fraudes;
  • Proteger usuários;
  • Monitorar atividades suspeitas.

5. Base Legal para Tratamento

Os dados são tratados conforme bases previstas na LGPD:

  • Execução de contrato;
  • Cumprimento de obrigação legal;
  • Legítimo interesse;
  • Consentimento.

6. Compartilhamento de Dados

A CMK Cogit poderá compartilhar dados com:

  • Provedores de infraestrutura;
  • Serviços de pagamento;
  • Ferramentas utilizadas na operação;
  • Parceiros necessários para execução contratual.

A empresa não comercializa dados pessoais.

7. Armazenamento dos Dados

Os dados são armazenados em ambientes protegidos, utilizando medidas técnicas e administrativas para reduzir riscos.

Os dados são mantidos pelo período necessário para:

  • Cumprimento contratual;
  • Obrigações legais;
  • Defesa de direitos.

8. Segurança da Informação

A CMK Cogit adota práticas como:

  • Controle de acesso;
  • Senhas protegidas;
  • Monitoramento;
  • Backup;
  • Restrição de permissões.

9. Cookies e Tecnologias Semelhantes

A plataforma pode utilizar cookies para:

  • Melhorar experiência;
  • Analisar utilização;
  • Personalizar conteúdos.

O usuário poderá configurar preferências no navegador ou gerenciar suas opções em .

10. Direitos dos Titulares

Conforme a LGPD, o usuário pode solicitar:

  • Confirmação do tratamento;
  • Acesso aos dados;
  • Correção;
  • Exclusão quando aplicável;
  • Portabilidade;
  • Revogação de consentimento.

11. Solicitações de Privacidade

Para exercer seus direitos, o usuário pode entrar em contato:

E-mail: contato@cmkcogit.com.br

12. Dados de Menores

Os serviços da CMK Cogit não são destinados a menores sem autorização dos responsáveis legais.

13. Alterações desta Política

Esta Política poderá ser atualizada para refletir:

  • Mudanças legais;
  • Novas funcionalidades;
  • Melhorias internas.

14. Encarregado de Dados (DPO)

Responsável: Cauan Rodrigues, Kaike Oliveira, Murilo Silva.

Contato: contato@cmkcogit.com.br

15. Foro e Legislação

Esta Política segue a legislação brasileira, especialmente:

  • Lei Geral de Proteção de Dados (Lei nº 13.709/2018);
  • Demais normas aplicáveis.
